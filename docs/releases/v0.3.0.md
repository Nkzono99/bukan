# Bukan v0.3.0

BukanをCLI・MCP・Codexプラグインとして利用する版です。v0.2.2のデスクトップGUIは廃止し、文献管理と研究エンジンをCodexなどのMCPクライアントから操作します。

## 主な変更

- 文献検索・PDF取得用MCPと、研究記録用MCPを提供。全文読解ノート、主張と根拠、論文間の関係、研究wikiを同じ研究DBに保存します。
- wikiの改訂、根拠の更新確認、未統合の研究記録、文献ごとの並列レビュー作業を管理します。
- 公開版・プレプリントの候補検索、URL確認、取得状況の履歴保存に対応しました。
- Paperpileへの文献登録をMCPから実行できます。Google Chromeと初回の`python -m bukan paperpile login`が必要です。登録先はMy Libraryです。
- PaperpileのAuto updateとPDF検索を行う手順をスキルに追加しました。この後処理は、Paperpile拡張機能が有効なブラウザをホストが操作して行います。登録MCP自体には含まれません。
- pipで導入できるwheel、AppData等への初期配置、`python -m bukan update`による導入済み本体・プラグインの更新を追加しました。
- MCPの通信・ツール定義・文献リスト保存を分離し、ノートとwikiの出力保護処理を共通化しました。

## 導入・更新

Python 3.11以上の64-bit環境で、OSに合うwheelをこのリリースからダウンロードします。Windowsの例です。

```powershell
python -m pip install --upgrade ./bukan-0.3.0-py3-none-win_amd64.whl
python -m bukan install
```

初回は続いてCodexの個人マーケットプレイスからBukanプラグインを追加します。登録コマンドはインストール完了時にも表示されます。すでに導入済みなら、上の`install`の代わりに`python -m bukan update`を実行できます。`update`はpipで導入済みの版を反映し、最新版のダウンロードは行いません。

WindowsとLinuxのx86_64向けにwheelとzipを配布します。LinuxではPopplerを別途用意してください。Paperpile登録にはPlaywrightが対応する環境も必要です。Windowsのzipには`install.cmd`を同梱します。PyPIにはまだ公開していません。

## 既存データと確認範囲

既存の研究ワークスペースを引き継ぎ、更新時に別の研究DBへコピーしません。GUI版からはCLI・MCPの導入手順に切り替えてください。旧GUIの自動更新機能ではこの配布物を導入できません。Paperpile同期フォルダへの直接アクセスは引き続き読み取り専用です。

Paperpileの登録結果ではブラウザ内の所蔵確認とサーバー同期を区別します。PDF取得、Drive同期、Bukanでの索引化、全文読解も別々に確認します。ノート・wikiの出力は手編集を上書きせず、研究内容の科学的な妥当性はエージェントによる読解と独立点検で確認します。
